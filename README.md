♟️ Simple Web Chess

A simple browser-based chess game made using HTML, CSS, and JavaScript. This project allows two players to play chess on the same device with a clean and easy-to-use interface. The game includes a functional chess board, movable pieces, turn-based gameplay, move popups, and a highlight system to make piece movement easier to understand.

The goal of this project was to create a lightweight and fun chess experience without using any external libraries or complicated systems. Players can take turns moving white and black pieces directly in the browser. Whenever a player makes a move, a popup message appears showing whose turn it is, making the gameplay more interactive. A highlight mode was also added to visually show selected pieces and possible movement areas, helping players keep track of the game more easily.

✨ Features:
1 ♟️ Fully working chess board
2 👥 1v1 local multiplayer on the same device
3 🔄 Turn-based gameplay
4 💬 Popup messages for White and Black turns
5 🎯 Highlight mode for selected pieces
6 🌐 Runs directly in the browser
7 🎨 Simple and clean UI
